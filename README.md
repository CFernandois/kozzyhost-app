# KozzyHost

[KozzyHost](https://kozzyhost.cl) es una app gratis para Android para quien arrienda departamentos por días: calendario sincronizado con Airbnb y Booking, cobros con link de pago y reportes por mes y por propiedad. Toda la información está en **[kozzyhost.cl](https://kozzyhost.cl)**.

Este repositorio solo guarda los APK publicados (en [Releases](https://github.com/CFernandois/kozzyhost-app/releases)); no tiene el código de la app. Para instalarla, descárgala desde [kozzyhost.cl/descargar](https://kozzyhost.cl/descargar).
